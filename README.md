# Unemployment and Mental-Health Analysis

An R Markdown analysis exploring relationships between unemployment indicators and mental-health outcomes. It includes data cleaning, exploratory analysis, correlation-based feature selection, train/test splitting, and classification with random forest and k-nearest neighbours.

## Requirements

R, RStudio, and the packages used in the notebook, including `readxl`, `dplyr`, `psych`, and `caret`.

## Run

Open `R programming.Rmd` in RStudio, make the referenced input data available, and knit or run the sections in order.
